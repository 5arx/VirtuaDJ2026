The Project

This constitutes my submission for module SEM334 Virtual Reality.

The brief was to develop a working three-dimensional model using VRML and javascript.

The model is based on the industry-standard Technics SL1210 mkIII turntable but colours have been changed and much of the geometry has been simplified.


Technical Notes 

The model was created in VRML 2.0 using VRMLPad from Parallel Graphics Ltd.

Some of the more intricate geometry was generated by drawing in 3D StudioMax and exporting as VRML 2.0 code.

The sound files used were either recorded from vinyl using an SL1210 turntable or taken from a audio compact disk. All sounds were edited using SoundForge 4.0.

The accompanying html files were created using MS Word 97.

All code tested on a 450MHz Pentium III running MS Windows 97. Virtual Reality files tested using Cosmo Player 2.1 for Netscape Navigator 4.0.
