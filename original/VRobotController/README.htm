VRobot: Virtual Robot simulator and controller.



The vr robot prototype may be viewed using a cosmoplayer-enhanced web browser (e.g. Netscape/I Explorer). The source file is "robotp1.wrl".
This prototype allows the basic functionality of the virtual robot arm to be observed.
 

The Java GUI may be viewed using "appletviewer interf.html" in the appropriate directory.

The GUI will allow control of both virtual and realworld robots.
In addition, the editor allows the creation, testing and running of robot control programs which may be saved and run by either virtual or realworld device.
